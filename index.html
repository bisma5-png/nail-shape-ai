    AI & Computer Vision Architecture

    NailSense AI uses a hybrid landmark + morphological geometry pipeline designed to run in real time on browsers or edge devices (Raspberry Pi, Jetson Nano, or ESP32-S3 camera node + host):

    1. Stage 1 — Keypoint Localization: MediaPipe Hands detects 21 3D hand landmarks. For each finger, the vector from DIP (distal interphalangeal joint) to TIP establishes the nail orientation angle θ.
    2. Stage 2 — Axis-Aligned ROI & Segmentation: A patch around the distal phalanx is rotated by -θ. Color-space thresholding (skin tone vs. nail plate luminance/saturation gradient + contrast) isolates the nail plate contour.
    3. Stage 3 — Geometric Feature Extraction: We measure proximal width W_prox, mid-plate width W_mid, distal width W_dist, and nail length L to compute:
      • Aspect Ratio = W_mid / L
      • Tip Taper = 1 - (W_dist / W_mid)
      • Sidewall Flare = (W_dist - W_prox) / W_prox
    4. Stage 4 — Technician Rule Engine (+ Optional VLM): Maps geometry features to the 6 nail bed archetypes and generates salon structural parameters (apex %, pinch window, form tilt, and optical elongation art).
